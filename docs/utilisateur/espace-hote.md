# Espace hôte — Guide utilisateur

**Préfixe :** `/host` (connexion avec rôle hôte requise)

## Tableau de bord

Vue d’ensemble : établissements, chambres, réservations récentes.

## Établissements

- `/host/property` — liste
- `/host/property/new` — créer
- `/host/property/:id` — détail, équipements, chambres

## Chambres

Depuis la fiche établissement : créer, modifier, photos, tarifs, dates bloquées.

## Réservations

`/host/reservations` — liste, annulation, signalement no-show.

## Messages

`/host/messages` — conversations avec vos voyageurs.
