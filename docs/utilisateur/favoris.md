# Favoris — Guide utilisateur

**Route :** `/account/favorites`

## Utilisation

1. Sur une fiche chambre, cliquez le **cœur** (connexion requise)
2. Retrouvez toutes vos chambres sauvegardées dans **Favoris**
3. Cliquez une carte pour rouvrir la fiche ou retirez un favori

## Notes

- Les favoris sont liés à votre compte, pas au navigateur seul.
- Retirer un favori ne supprime pas une réservation en cours.
