# Avis — Guide utilisateur

## Quand laisser un avis ?

Après un **séjour terminé** et une réservation **confirmée**, depuis **Mes achats**.

## Contenu

- Note de 1 à 5 étoiles
- Commentaire texte (optionnel selon configuration)

## Modération

Votre avis est examiné avant publication sur la fiche chambre. Vous le retrouvez dans votre historique avec son statut.

## Consultation

Les avis approuvés s’affichent sur `/rooms/:slug` avec la note moyenne.
